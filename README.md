# VolumeLimiter

This app allows you to shrink the range of the volume you can adjust so you have more precise control. It is especially useful if you, for instance, never sets a volume above 20\% with AirPods.

## Usage

```bash
swift VolumeLimiter.swift
```

A menu bar item where you can adjust the volume will appear. You may minimize the terminal that is running this command.
